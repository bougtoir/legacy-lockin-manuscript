# 12 — Nature viability assessment

Verdict scale per spec: NATURE PATH STRONG GO / CONDITIONAL GO / PIVOT / NO-GO.
"Statistical significance alone is insufficient."

## Verdict: **NO-GO** (for this result as a Nature primary claim)

Rationale:

1. **No primary confirmatory signal.** H1 p=0.149, H2 p=0.610 on the single
   frozen opening. The headline cannot be written.
2. **The result is not a tight null either.** H1's CI [−0.45, +0.07] includes
   large barrier effects — under-powered rather than evidence of absence
   (sim power ~50% at β=−0.15, ~6% at β=−0.05). "We found nothing" is the
   weakest empirical position for a top general-interest venue.
3. **The mechanism leg failed.** Capacity enablement (H2) is essentially absent
   — the interactive "civilization constrains adaptation" mechanism is not
   demonstrated even directionally on this branch.
4. **Programme-level accumulation.** This is the third frozen branch; the
   running record is two informative nulls (agriculture, prospectively locked)
   + one spec-dependent weak negative (coastal) + this null. The cumulative
   evidence now disfavors the umbrella hypothesis more than any single branch.
5. What remains publishable: the consistent barrier-direction signature on the
   flood-departure margin (extensive −0.19, intensive −0.55 p=0.003, lag-1
   −0.38 p=0.012) is a credible *specialist-journal* finding (e.g., a US
   managed-retreat/programme-entry paper), not a Nature general claim.

## What would have changed the verdict

- CONDITIONAL GO would have required a significant H1 on the primary with the
  level pattern in 05 surviving robustness — it does not.
- PIVOT would apply if the data showed a different strong estimand worth
  re-locking; the intensive-margin negative is real but conditioning-on-entry
  makes it a weaker general-interest object.
