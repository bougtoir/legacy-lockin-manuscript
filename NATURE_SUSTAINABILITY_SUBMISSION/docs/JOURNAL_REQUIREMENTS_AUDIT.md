# Journal requirements audit — Nature Sustainability (Article)

Access date: 2026-10-04 (UTC). Source: official Nature Portfolio pages only.

| Requirement | Official rule | Source URL |
|---|---|---|
| Title | up to 10 words (or 90 characters) | https://www.nature.com/natsustain/content |
| Main text | up to 3,500 words excluding abstract, Methods, references, figure legends | same |
| Abstract | up to 150 words, unreferenced | same |
| Display items | up to 6 (figures and/or tables) | same |
| Structure | Introduction (no heading) → Results → Discussion → Methods; Results/Discussion/Methods divided by topical subheadings | same |
| References | guideline ~50 | same |
| Initial submission format | PDF, Word or TeX; no special formatting required at initial submission | https://www.nature.com/natsustain/submission-guidelines/initial-formatting |
| Peer review | peer reviewed; optional double-anonymized review | https://www.nature.com/natsustain/submission-guidelines |
| Methods placement | after Discussion | natsustain/content structure |
| Received/accepted dates | included | same |

Standard Nature Portfolio policy items (apply via submission system):
- Data Availability statement required; Data/Code availability sections in manuscript.
- Competing interests declaration required.
- Author contributions (CRediT-style) required.
- Source Data files may be requested at revision for figures containing quantitative data — `source_data/` prepared.
- Extended Data figures/tables allowed for peer-review transparency items.

Compliance mapping:
- Title: 7 words ✓ ("When does inherited structure become adaptation lock-in?")
- Abstract: ≤150 words ✓ (see WORD_COUNT_AUDIT)
- Main text (Intro+Results+Discussion): ~2,000 words < 3,500 ✓
- Display items: 5 figures + 1 table = 6 ✓
- References: 43 < 50 ✓
- Structure: Introduction unheaded → Results → Discussion → Methods → declarations → References ✓
