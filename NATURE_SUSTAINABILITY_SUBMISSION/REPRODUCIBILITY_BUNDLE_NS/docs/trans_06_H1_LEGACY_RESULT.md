# 06 — H1 legacy result

**Frozen hypothesis:** older baseline housing-stock legacy moderates the
flood-demand → transformational-departure-entry relationship negatively
(legacy barrier): β(demand × legacy) < 0.

**Estimate:** −0.1923 [−0.4537, +0.0692], p = 0.149 (county-cluster CRV1).

## Classification: **RESULT B — null (barrier-direction point estimate)**

- Sign is in the theorized direction and the effect is not tiny in levels
  (demand response ~+3.0 pp vs +1.9 pp annual hazard across the legacy IQR —
  see 05), but the CI crosses zero and p = 0.149.
- The simulation says the design has ~50% power at β = −0.15 and ~6% at
  β = −0.05: a true small-to-moderate barrier could produce exactly this
  result. The null is *not* an informative tight bound on zero (CI includes
  −0.45, a large barrier).
- Supporting, but non-primary, evidence: the secondary intensive margin shows
  the same negative sign with precision (see 09); lag-1 demand variant turns
  the extensive-margin interaction significant negative (−0.380, p = 0.012).
  These are recorded, not used to upgrade the classification.

Not A (would require the primary CI entirely below 0), not C (positive), not D
(unstable: sign is negative in 6/9 numeric variants; leave-one-state-out range
−0.14 to −0.26, always negative, no state drives the result).
